# DentalFlow Product Documentation

## Purpose

This directory contains the complete functional definition of DentalFlow.

Unlike the architecture documentation, which explains how the platform is built, this documentation explains what the product is, who it is for, how users interact with it and what experience the platform must provide.

Every frontend implementation, UI decision, UX improvement and product feature must follow this documentation.

# Rule

If architecture documentation conflicts with product documentation:

Architecture defines HOW.

Product defines WHAT.

Both must always remain synchronized.
