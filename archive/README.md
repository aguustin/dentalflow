# archive/

Deprecated or superseded documents.

## Purpose

When a document in `docs/`, `decisions/`, `workspace/`, or `research/` is no longer current, it is moved here rather than deleted. This preserves the historical record of how the system evolved.

## Conventions

- Prefix archived files with the date they were archived: `2026-06-26-original-name.md`
- Add a one-line note at the top of the file explaining why it was archived and what superseded it
- ADRs are never archived here — a superseded ADR stays in `decisions/` with its status updated to `Superseded` and a reference to the new ADR
- Do not reference files in `archive/` from production code or active documentation
