# workspace/

Working area for in-progress technical work that is not yet ready to become a formal document.

## Purpose

This folder is a **scratchpad for engineers**, used to capture:

- Ongoing design work that has not reached a decision
- Draft ADRs being discussed before promotion to `decisions/`
- Implementation notes for complex features under development
- Diagrams and sketches (Mermaid, draw.io exports, ASCII)
- Meeting notes with technical action items

## Conventions

- Files should be named `YYYY-MM-DD-topic.md` or `author-topic.md`
- Nothing in this folder is authoritative — it is ephemeral work
- When a piece of work is concluded, either promote it to `docs/` / `decisions/` or move it to `archive/`
- Do not reference files in `workspace/` from production code comments
